# unicorntail
🦄 A powerful micro-SaaS page builder for everyone. Design stunning landing pages visually, publish instantly to custom subdomains, or export the entire project into clean, production-ready Next.js &amp; Tailwind CSS code! ⚡

## 🚀 The Vision
Most page builders capture your data and lock you into their ecosystem. UnicornTail converts your visual designs into an Abstract Syntax Tree (AST) stored as `JSONB` in PostgreSQL, then compiles it dynamically on-demand or exports it directly into your personal GitHub repositories as standard, modular React components.

## 🛠️ Tech Stack
- **Frontend & Editor:** Next.js 15 (App Router), Tailwind CSS, Craft.js
- **Backend API:** NestJS (TypeScript) adhering to Clean Architecture principles
- **Database:** PostgreSQL (`JSONB` for schema-less components tree)
- **Authentication:** NextAuth.js (Auth.js) with GitHub OAuth
